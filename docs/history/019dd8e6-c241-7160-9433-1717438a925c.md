Tôi cần biên dịch được tuyệt đối, vậy phải làm sao?


### Trợ lý (final_answer)

Không thể đạt “tuyệt đối” nếu phụ thuộc QuickLaTeX undocumented. Nó có thể fail vì thiếu package/library, sandbox hạn chế lệnh LaTeX, lỗi nội bộ `Cannot create svg file`, timeout, rate limit, hoặc response format đổi.

Muốn biên dịch gần như tuyệt đối, hướng đúng là:

1. **Không dùng QuickLaTeX làm nguồn chính**
   Dùng QuickLaTeX chỉ như fallback nhanh, không phải pipeline chính.

2. **Tự host LaTeX renderer**
   Chạy server-side bằng môi trường TeX đầy đủ:
   - `texlive-full`
   - `standalone`
   - `tikz`
   - `pgfplots`
   - `dvisvgm`
   - `poppler-utils` hoặc ImageMagick nếu cần PNG
   - compile bằng `latex`/`pdflatex`/`lualatex`

3. **Pipeline chuẩn**
   Với mỗi `tikzCode`:
   - wrap vào document LaTeX standalone
   - compile `.tex -> .pdf` hoặc `.dvi`
   - convert sang `.svg` hoặc `.png`
   - upload ảnh vào Firebase Storage / local storage / S3
   - lưu URL ảnh vào Firestore
   - nếu lỗi, lưu log compiler đầy đủ cho giáo viên sửa

4. **Không convert trực tiếp trong request lưu đề nếu đề lớn**
   Nên dùng job queue:
   - giáo viên bấm lưu
   - lưu đề với trạng thái `processing`
   - server convert từng hình
   - cập nhật `tikzImageUrl`
   - khi xong chuyển sang `ready`

   Nếu convert trong HTTP request, đề nhiều hình sẽ dễ timeout.

5. **Cần chuẩn hóa preamble**
   Cho giáo viên nhập thêm preamble riêng hoặc cấu hình mặc định rộng hơn:
   - `\usepackage{tikz}`
   - `\usepackage{pgfplots}`
   - `\pgfplotsset{compat=1.18}`
   - `\usetikzlibrary{...}` nhiều hơn
   - các package hay dùng trong đề toán Việt Nam như `tkz-tab`, `tkz-euclide`, `commath`, `esvect`, `mathrsfs`, v.v.

Khuyến nghị thực tế cho project của bạn:

- **Ngắn hạn:** giữ QuickLaTeX nhưng không gọi là “tuyệt đối”; thêm danh sách lỗi và cho giáo viên sửa TikZ.
- **Đúng bài toán:** tạo một API/service riêng `render-tikz` chạy Docker TeX Live đầy đủ, rồi app Next.js gọi service đó.
- **Nếu deploy Vercel:** không nên compile LaTeX trực tiếp trong Vercel Function. Hãy dùng Render/Fly.io/Railway/VPS/Docker service riêng vì cần binary LaTeX và filesystem tạm.

Nếu bạn muốn, bước tiếp theo tôi nên chuyển kiến trúc sang **self-hosted TikZ renderer bằng Docker + API route/service**, thay vì cố vá QuickLaTeX.
